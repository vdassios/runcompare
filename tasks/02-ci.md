# 02 · CI

**Milestone** M1 · **Depends on** 00 · **Parallel with** 01, 05 · **Branch** `task/02-ci`

## Goal
Run lint, typecheck, tests and build on every PR with GitHub Actions.

## Read first
`tasks/README.md` and `PLAN.md` §7 and §9.

## You own
`.github/workflows/ci.yml`

## Requirements
Runs on PRs and pushes to `main`. One job, **`checks`**: ubuntu, Node 22, `npm ci`, then lint, typecheck, `npm test` and build. The job name must be exactly `checks`, because branch protection requires it.

## Acceptance
- Pushing the branch gives a green `checks` job on the PR.

## Out of scope
Test data. Tests use the real fixtures through `src/test/fixtures.ts` (09, 21).
